# Proyecto_4_Analisis_RappiPlus

**Descripción:** Se realizó un análisis completo de negocio, para identificar si se estaban obteniendo ganancias, así como identificar los gastos más grandes de las campañas de marketing. Para que al final se creara un Dashboard ejecutivo que permite el visualizar de manera eficiente el estado del negocio.

**Título:** Análisis de Ganancias y Dashboard Ejecutivo en Power BI

-**Desafío:** El cliente necesitaba saber como estaba rindiendo el negocio, además de tener un dashboard que le permitiera hacer deep dives de los clientes para obtener contexto del mismo. Además se daban sugerencias de mejoras en un experimento realizado, pero no se podía saber si los cambios eran significativos.

- **Proceso:** Se comenzó con una limpieza de 2 datasets que proporcionaban el estado del negocio. Despues de la limpieza de datos, se hizo un join que nos permitia obtener un entendimiento del negocio. Se hizo el analisis estadistico del experimento y se dieron sugerencias basadas en los resultados obtenidos. Finalmente se exportaron los dataset limpios en Power Bi y se hizo un dasboard ejecutivo.

- **Resultado:** El cliente pudo saber el estado del negocio ademas de cuantificar que tanto impacto tenían los experimentos que se llevaban a cabo. Finalmente tiene acceso a toda esta información de manera sencilla y en un solo lugar.
