# Proyecto_4_Analisis_RappiPlus

**Descripción:** Se realizó un análisis completo de negocio, para identificar si se estaban obteniendo ganancias, así como identificar los gastos más grandes de las campañas de marketing. Para que al final se creara un Dashboard ejecutivo que permite el visualizar de manera eficiente el estado del negocio.

**Título:** Análisis de Ganancias y Dashboard Ejecutivo en Power BI

- **Desafío:** El cliente necesitaba saber como estaba rindiendo el negocio, además de tener un dashboard que le permitiera hacer deep dives de los clientes para obtener contexto del mismo. Además se daban sugerencias de mejoras en un experimento realizado, pero no se podía saber si los cambios eran significativos.

- **Proceso:** Se comenzó con una limpieza de 2 datasets que proporcionaban el estado del negocio. Uno de los data sets contenía mas de 25k entradas. Donde cada fila representaba una orden realizada en la aplicación. A su ves el segundo dataset nos proporcionaba el país y el tipo de marketing que se utilizaba. Finalmente el ultimo dataset solo proporcionaba las claves primarias de las campañas utilizadas. Al inicio se observaba que había datos nulos. Se intentó imputar los datos mediante el contexto de columnas adyacentes. Pero esto no fue posible, así que se eliminaron. Al ser menos del 2% de datos esto no afecto el análisis. Después de la limpieza de datos, se hizo un join que nos permitía obtener un entendimiento del negocio, para lograr esto se localizaron las claves primarias y se hizo una limpieza de formato para evitar errores. Donde logramos obtener una idea del margen de ganancias. A su vez se hizo el análisis estadístico del experimento que se estaba llevando acabo. Donde también analizamos cambios que habían sido sugeridos y pronosticábamos que tanto impacto podrían tener. Con base en los datos y los resultados obtenidos se dieron sugerencias que permitirían una fácil toma de decisiones. Finalmente se exportaron los dataset limpios en Power Bi y se hizo un dasboard ejecutivo.

- **Metodología:** Se inició con la identificación de nulos, sentinels y datos faltantes. Estandarización de las columnas clave para facilitar el JOIN, así como conversión de fechas a formato datetime64. Y se hizo uso de graficas para facilitar la digestión de la información

- **Insights:** Mediante el uso de SQL se realizó una cohorte donde se identificó que el paso donde mas se perdían clientes era en el checkout con un 13% de dropoff. Se sugirió conversar con el equipo encargado de la pagina para saber si esta podría ser difícil el agregar un método de pago. En cuanto a el análisis del experimento A/B que se llevaba acabo se identificó que los cambios implementados no representaban un gran cambio en las métricas. Ya que la mejora era menor al 1%, sin embargo se recomendó hablar con el equipo encargado para verificar si los costos y las ganancias son suficientes para la implementación de la misma. Finalmente se diseñó un dashboard ejecutivo que permitía una fácil visualización de los KPIs más importantes así como a su vez nos permitía tener un insight mas claro del cliente.

- **Resultado:** El cliente pudo saber el estado del negocio además de cuantificar que tanto impacto tenían los experimentos que se llevaban a cabo. Finalmente tiene acceso a toda esta información de manera sencilla y en un solo lugar.
